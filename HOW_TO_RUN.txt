================================================================================
HOW TO RUN THE INVENTORY MANAGEMENT SYSTEM
Windows quick start
================================================================================

Install these tools once:

  * PHP 8.4.1 or newer
  * Composer 2
  * Node.js with npm (a supported LTS release)
  * Git

The full installation guide, including PHP extensions, MySQL, demo accounts,
updates, and troubleshooting, is in docs/GROUPMATE_SETUP.md.

--------------------------------------------------------------------------------
FIRST-TIME SETUP
--------------------------------------------------------------------------------

Open PowerShell in the folder where you want to keep the project and run:

    git clone https://github.com/JustinReyes28/Inventory-Management-System-School-Project-Laravel.git InventoryManagement
    cd InventoryManagement
    .\setup.bat
    .\run.bat

Open http://127.0.0.1:8000. Keep the run terminal open; press Ctrl+C to stop
the app.

The setup script installs locked dependencies, creates a local .env and
application key when needed, creates and migrates a SQLite database, seeds
demo accounts and inventory, and builds the React assets. MySQL and Apache are
optional. Each groupmate gets a separate local database.

Fresh local demo logins:

    Role        Username     Password
    Admin       admin        Admin@1234
    Employee    employee     Employee@1234
    Employee    employee2    Employee2@1234
    User        viewer       Viewer@1234

Reruns keep your existing .env, nonempty application key, passwords for
existing demo accounts, and inventory. They never reset database tables.

--------------------------------------------------------------------------------
DAILY USE
--------------------------------------------------------------------------------

From the cloned project folder, start the built app with:

    .\run.bat

For React development with hot reload, stop that server and run:

    composer dev

Open the Laravel URL shown in the terminal (normally http://127.0.0.1:8000).
Keep the terminal open while using the app. React changes reload through Vite.

To pull project updates, stop the app first, then run:

    git pull --ff-only
    .\setup.bat
    .\run.bat

The setup script applies pending migrations and rebuilds frontend assets. Do
not use migrate:fresh to update a database; it deletes tables and records.

================================================================================
END OF GUIDE
